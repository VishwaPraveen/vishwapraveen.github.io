RideAssist

Motorcycle. Phone. Rider. One System. Motorcycle + Phone + Rider = One System.


RideAssist is a custom-engineered TFT dashboard system that links rider, motorcycle, and smartphone into a single connected loop — built from the ground up using ESP32, BLE, and sensor fusion.

Motorcycle Data

  • Real-time speed & max speed tracking
  • RPM, ODO, and TRIP metering
  • Compass heading & bearing calculation
  • Lean angle with max lean capture (IMU-based)
  • Center of gravity meter
  • TPMS — direct tire pressure decoding
  • Onboard battery voltage monitoring

Phone Data, Mirrored

Synced over BLE to bring smartphone context onto the dash:

  • Signal strength & battery % (with charge/discharge state)
  • Live time
  • Call & message notifications
  • Music playback info
  • Turn-by-turn navigation with directional icons

The System

A companion Android app handles device pairing, data sync, and control — communicating with the dashboard over BLE with end-to-end encryption.

Three components. One continuous feed of information. Built for the ride.

Smart Home Automation

Set it once. Let it run itself.

A BLE-controlled relay system built on ESP32, designed to automate everyday switching — lights, filters, pumps — with scheduling smart enough to run unattended and simple enough to override in a tap.

Control

  • Dedicated Android app for pairing, monitoring, and manual override
  • Bluetooth Low Energy communication, no cloud dependency
  • Manual or Auto mode per relay

Scheduling

  • Two independent timeframes per relay, including overnight wraparound
  • WiFi-synced NTP time, periodically refreshed to stay drift-free
  • Runs reliably even when the phone isn't connected

Multiple relay channels, one ESP32, and an app that talks to it — built to be reliable enough to forget it's even there.
